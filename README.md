# 🎮 Match-3 Power Puzzle

An interactive browser-based **Match-3 puzzle game created using Generative AI** as part of the **Day 2 – Game Creation** task.

The game was generated using **Kimi AI** from a natural-language prompt describing the game concept, gameplay mechanics, interface, features, and functionality.

> **Idea → Prompt → Kimi AI → Functional Game**

---

## 📌 Overview

**Match-3 Power Puzzle** is a browser-based puzzle game where players swap adjacent tiles to create combinations of three or more matching tiles.

When a valid combination is created, the matching tiles are removed, new tiles fall into place, and additional matches can occur through cascading effects.

The main objective is to achieve the **target score of 2000 points** within the available number of moves.

The project demonstrates how **Generative AI can transform a natural-language idea into a functional interactive application**.

## 🎮 How to Play

### Step 1 — Select a Tile

Click or tap a tile on the game board.

### Step 2 — Select an Adjacent Tile

Select a tile next to the first tile to swap their positions.

### Step 3 — Create a Match

Try to create a horizontal or vertical combination of **3 or more matching tiles**.

### Step 4 — Clear the Match

Matching tiles are automatically removed from the board.

### Step 5 — Cascading

New tiles appear to fill the empty spaces.

Additional matches may occur automatically, creating cascading combinations.

### Step 6 — Earn Points

Successful matches increase the player's score.

### Step 7 — Reach the Target

The objective is to reach the **target score of 2000 points** within the available moves.
